# 0156 — The silence sentence is amended for the reaction, not excepted beside

Date: 2026-08-30, with unit 39.

## Context

The helpful arm's silence teaching held the strongest sentence in the answering prose. Its
wording, verbatim until this unit: "they get nothing from you, not an answer, not an
acknowledgment, not a comment."

That sentence is about ACTS. A reaction is an act, and the whole point of it is that it
lands on exactly the messages this sentence covers. Left as written, the composed prompt
would forbid on one line what it invites two paragraphs later.

Decision 0148, taken the day before with unit 40, refused to carve an exception into this
sentence for the heads-up line and resolved that case by wording the new sentence instead —
"amending the silence teaching to carve out an exception" is named there as the rejected
alternative. It could refuse, because the heads-up line added no new act: it is text, in a
turn that already had something to say, and the sentence never covered it.

## Decision

This unit adds an act, so the sentence itself changes. Its two halves are pinned byte for
byte as named constants, and the composition interpolates them so no re-wrapping can reword
them.

The rule becomes, verbatim:

> they get nothing from you in words: not an answer, not an acknowledgment, not a comment.

And the carve-out joins it in the same place, verbatim:

> The one exception is the emoji reaction: where you would otherwise end an empty turn but a
> message genuinely lands — a share, a milestone, a joke that landed — you may put
> one reaction on it instead. A reaction never rides with words on the same message, most
> messages deserve no reaction either, and silence stays the default.

The amendment scopes the rule to words, which is what it always meant, and the carve-out
carries every condition the reaction is bounded by. Nothing about the silence default
weakens: the carve-out's own last clause says so, and the assistant still ends a turn with
no text when it has nothing to say.

This supersedes 0148 for THIS case and for no other. That decision's own resolution stands
for the heads-up line, and its reasoning is what distinguishes the two: a wording problem in
another sentence is solved by wording, and a new act is not.

The ADDRESSED arm is deliberately unamended. There an unaddressed message opens no turn at
all, so the chatter carve-out never meets that arm's sentence. What the addressed mode does
get is the react teaching, which composes unconditionally and whose empty-turn clause
legitimately covers an addressed message that lands with nothing to say — a share aimed at
the assistant may draw a reaction there too, which contradicts nothing that arm states.

## Rejected alternatives

- **A carve-out sentence beside the untouched rule.** The composed prompt would contradict
  itself on a literal read — the rule forbidding an acknowledgment, the next paragraph
  inviting one — which is the exact collision 0148 documents.
- **Leaving the sentence alone and wording the react teaching around it.** That is 0148's
  own resolution, and it works only for a sentence the new text does not actually violate.
  A reaction on an unaddressed message is an acknowledgment of it, and no wording of the
  invitation changes what the rule says about the act.
- **Dropping "not an acknowledgment" from the rule.** It would fix the collision by
  weakening the rule for words too, which is the half that must not move.
- **Amending both arms for symmetry.** Symmetry is not a reason, and the addressed arm's
  sentence governs a case the carve-out never reaches.
