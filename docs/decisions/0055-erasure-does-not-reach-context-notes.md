# 0055 — Erasure does not reach context notes — OPEN

Date: 2026-08-23. In the 0045 lineage; revisited when the framework offers
the path.

## Context

A rules text is governance prose that can in principle name a person, and
the note table carries topic and text with no principal id, so erasure
cannot reach it even in principle.

## Decision

Accepted with its reasoning recorded: the note quotes the group's own
published governance, not a person's conversation, and the erasure write
path for non-message blocks is the same framework seam the tool-block OPEN
(decision 0045) waits on. OPEN.

## Rejected alternatives

- **Blocking the unit on a framework erasure seam.** The same reasoning as
  0045: the unit would wait on a release the assistant does not control,
  for a surface whose personal-data exposure is marginal.
- **A principal id on the note table.** The note records what the group
  published, not who published it; inventing an author column would store
  more personal data to make erasure apply, backwards.
